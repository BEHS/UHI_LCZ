# Urban Heat Island (UHI) effect: Local Climate Zones
Github repository associated with "Comparing Local Climate Zones for Three Cities Across the Tropics Reveals Differential Impacts of the Urban Heat Island Effect" study

The geospatial data associated with the study (i.e., LCZ maps for 2016 and 2023, for Dhaka, Kampala, and San Salvador) are stored as GeoTIFs in the following sub-folder: https://github.com/BEHS/UHI_LCZ/tree/main/lcz_maps_2016-2023.
